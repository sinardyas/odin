# Learning Index

A personal learning repository. Each topic under [`topics/`](./topics/) is a
self-contained [`/teach`](https://github.com/mattpocock) workspace — its own mission,
lessons, references, and learning records. This index is the front door: it routes
to each topic's mission.

> **Routing note:** links below point at each topic's `MISSION.md` (the *why*), not the
> lessons. To read the lessons, open the HTML files in that topic's `lessons/` folder.
